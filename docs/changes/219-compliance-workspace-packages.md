# Make the compliance report also read shared packages in subfolder package.json files (#219)

## Change

| File | Content |
|---|---|
| `scripts/lib/compliance.mjs` | `repoStatus` reads both the root `package.json` and the subfolder `*/package.json` files registered in the manifest. If the version differs in any one place, it shows that value; if it is in none, the result is `없음` (none) |
| `scripts/test/compliance.test.mjs` | Tests a package only in a subfolder, a version that differs in only one folder, and a package that is nowhere |

## Why

- In `docs/compliance.md` of PR #201, workout-memo showed `✗ @sirloinbh/tsconfig 없음≠1.0.0` (`없음` = none).
- Sync puts `@sirloinbh/tsconfig` into `frontend/package.json` and `backend/package.json` as `templates/index.json` says, but the report read only the root `package.json`. Both files in workout-memo actually contain `1.0.0`.
