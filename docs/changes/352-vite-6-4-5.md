# #352 vite 6.4.5 보안 패치 반영

## 변경

| 파일 | 내용 |
|---|---|
| `versions.json`, `docs/versions.md` | frontend `vite` 6.4.4 → 6.4.5 |

## 왜

- `npm audit`가 vite 6.4.4에서 [GHSA-8g5g-mxqh-grgj](https://github.com/advisories/GHSA-8g5g-mxqh-grgj)(중간, `server.fs.deny` 우회)를 알린다. 영향 범위는 6.4.4뿐이고 6.4.5에서 고쳐졌다.
- 개발 서버에만 해당한다. 앱 개발 서버는 localhost에만 열리고 운영 이미지에는 들어가지 않는다.

## 14일 규칙 예외

- 6.4.5는 2026-10-21에 게시돼 이 변경일(2026-10-31)에 10일째다. `docs/dependency-policy.md`의 "릴리스 후 14일 경과"(2026-11-04)를 채우지 못한다.
- 사용자가 이 사실을 안내받고 2026-10-31에 이번만 예외로 진행하기로 정했다.

## 확인한 조건

| 조건 | 결과 |
|---|---|
| 정확한 버전 | 6.4.5 |
| 설치 스크립트 | 없음 |
| 게시자·저장소 | `github.com/vitejs/vite`, GitHub Actions 게시, 증명(attestation) 있음 |
| 의존성 | 6.4.4와 같음 |
| 함께 쓰는 패키지 | `vitest` 5.0.3(peer `^6.4.0`), `@tailwindcss/vite` 4.3.3(peer `^6`) 범위 안 |

## 동기화 PR에서 할 일

동기화 PR은 앱 `package.json`만 바꾸므로 lockfile을 맞출 때까지 CI의 `npm ci`가 실패한다. 승인된 설치는 사용자가 실행한다(`docs/dependency-policy.md`). 각 PR 브랜치에서 `npm install --ignore-scripts --package-lock-only`, `npm run lockfiles:sync`를 실행해 커밋한다.
