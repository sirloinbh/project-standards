# #353 도메인 규칙에 초·개월 단위 기간 기준 추가

## 변경

| 파일 | 내용 |
|---|---|
| `docs/conventions/domain.md` | 초·달력 개월을 쓸 수 있는 조건과 개월 더하기 규칙 추가, 형식 표에서 연결 |

## 정한 것

- 분 단위가 기본이고, 외부 자료나 공식 규정의 단위가 다를 때만 초·달력 개월을 쓴다.
- 앱이 지금처럼 중앙에 이슈를 열지 않아도, 이 조건에 맞으면 그 단위를 쓸 수 있다.
- 조건은 cert-manager 설계 문서의 두 예외(`duration_seconds`, `validity_months`)에 맞췄다. 코드 변경은 없다.

## 확인

- `npm run check` 통과.
- 말일 보정 예시는 이슈에 적힌 PostgreSQL 동작을 옮겼고, 실제 DB에서 실행하지 않았다.
