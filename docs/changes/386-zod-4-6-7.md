## zod 4 differences found in the apps

While moving the app code, I compared the behavior before the move with 4.6.7. Watch for the same points when creating a new app.

- Wrapping `.default()` in `.optional()` or `.partial()` still applies the default. Build the PATCH schema from a shape without defaults.
- String `.min()` and `.max()` also run after a type failure when the input has `.length`, so their messages are added. They count in code points, so emoji lengths also differ. Use `.refine` to keep the message.
- Put the array `.max()` before `.refine`. That way it rejects before reading the elements.
- `z.number()` rejects `Infinity` at the type stage, so a later `.refine` does not run.
- `z.uuid()` can reject values that used to pass. If you need the same range, use `z.guid()`.
- The `datetime` check is stricter. It rejects times without seconds and offsets without a colon.
