## Learned

- **`!` commands:** They run in bash, so the backslashes in Windows paths disappear. Use this form when passing on an app repo merge.

  ```
  ! powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$LOCALAPPDATA/sirloinbh-tools/gh-project.ps1" pr merge <번호> --repo sirloinbh/<리포> --merge
  ```

  (`<번호>` is the PR number and `<리포>` is the repo name.)

- **`TEST_DATABASE_URL`:** The environment variable on this PC points to study-log's `study_test`. If you run `npm run check` as is in another app, the DB tests fail because the tables do not exist. Create a temporary DB for each app and override this value.
