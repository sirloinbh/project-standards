## 알게 된 것

- **`!` 명령:** bash로 실행되어 Windows 경로의 백슬래시가 사라진다. 앱 리포 병합을 안내할 때는 다음 형식을 쓴다.

  ```
  ! powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$LOCALAPPDATA/sirloinbh-tools/gh-project.ps1" pr merge <번호> --repo sirloinbh/<리포> --merge
  ```

- **`TEST_DATABASE_URL`:** 이 PC의 환경 변수가 study-log의 `study_test`를 가리킨다. 다른 앱에서 `npm run check`를 그대로 돌리면 테이블이 없어 DB 테스트가 실패한다. 앱마다 임시 DB를 만들어 이 값을 덮어쓴다.
- **#392:** 고칠 파일은 이슈에 적힌 `backup.sh`가 아니라 `templates/app/deploy/backup.sh.tmpl`이다.
